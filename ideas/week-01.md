# Week 1 reel drafts (002–015)

Numbered so the scheduler's rotation (architect → list → detail → site) plays them in this order.
Folder name = the heading. Formats alternate: **V** = voiced 20–35 s, **S** = silent 7–15 s loop.
Every reel opens on its best frame and ends on 2–3 s of the website. Facts come from the site's own
building notes; lines marked † are extra facts — double-check before recording.

Batch plan: 002–007 → Oct 18–20 batch · 008–013 → Oct 21–23 · 014–015 start Oct 24–26.
